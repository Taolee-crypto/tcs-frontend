# TCS 권리관리 시범

TCS는 직접 유통하지 않는 공통 권리관리 인프라다. TimeLink와 외부 플랫폼은 같은 권한 기준을 적용한다.

/#/rights-pilot 경로에 권리자 등록·검토 제출, 협회 검토·이용허락 등록·철회, 플랫폼 사용량 보고 화면을 추가했다. 실제 MP3는 업로드하지 않고 브라우저에서 원본 SHA-256만 계산한다. 해시는 소유권 증명이 아니다.

Node 24 기반 tcs-backend를 127.0.0.1:8788에서 실행한 뒤 npm run dev로 접속한다. 접속키 설정은 백엔드 README 참조. 키는 브라우저 메모리에만 저장된다. GitHub Pages에는 API가 없으므로 시범 API 연결에는 별도 서버와 프록시가 필요하다.

검증: TypeScript/Vite 빌드 통과. 백엔드 5개 테스트에서 권리 검토, 역할·기관·플랫폼 격리, 사용량 중복·겹침·범위·철회, SQLite 재시작, HTTP 인증 확인. 브라우저 시각검사·전체 E2E·운영 배포는 미검증.

미구현: 실제 협회 연동, 운영 인증/SSO, 전자서명, 증빙 원문 보관·진위 확인, 공동 권리자 지분, 실제 MP3 공급·TL3 처리, TimeLink 운영 연동, 독립 재생 증명, 정책 적용·사용료 확정·청구·지급. 기본 TL은 보고된 초 단위이며 원화 사용료가 아니다. 외부에서 체결된 계약의 참조를 등록하는 기능이며 계약 체결 서비스로 표시하지 않는다.
