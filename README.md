# TCS Frontend

TCS is an independent, open global music-copyright management infrastructure. This repository contains the TCS public website and role-based portal frontend.

## Stack
- React + TypeScript
- Vite
- React Router
- Lucide icons

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Product boundaries
- TCS provides rights-management infrastructure; it does not distribute or sell music directly.
- TIMELINK and other distribution platforms remain independent and connect through common integration standards.
- Creator, association, platform-partner, and financial-institution data and permissions must remain separated.
- Royalty policy, membership eligibility, and financial decisions must be based on verified rules and authorized institutions.

The current frontend establishes the responsive public-site shell and initial information architecture. Portal workflows and backend integrations will be implemented in subsequent stages.
